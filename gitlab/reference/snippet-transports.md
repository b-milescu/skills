# GitLab snippet transport contracts

Stable `/gitlab` snippet names are workflow API; each table row is one snippet's transport contract. Machine-actionable source truth: `skill://gitlab/reference/snippet-metadata.json`. Markdown table is checked against this metadata by `tests/gitlab-snippet-metadata.sh`.

## Global rules

- **Transport order:** MCP first, guarded `glab` fallback second, local `git` for worktree/branch safety. Record `via=mcp` or `via=glab-fallback`; fallback never bypasses a guard phase and CI status is advisory.
- **Decision-grade reads:** Prefer `get_merge_request_workflow_snapshot`; use body-free `get_merge_request(include_description:false)` or `get_issue(include_description:false)` only for fields it lacks, and the bounded readers (`description_grep`, `body_grep`, `body_max_bytes`) for bodies. `list_*` results are candidate data; see [`bounded-reads.md`](bounded-reads.md).
- **GitLab Mutation Guard:** Every snippet with non-empty `allowed_mutations` follows the ordered guard in [`mutation-guard.md`](mutation-guard.md), including [`safe-text.md`](safe-text.md) validation of body-bearing mutations; machine schema: `skill://gitlab/reference/mutation-guard.schema.json`.

| `approval-confirmation` | `get_merge_request_approvals` plus `get_merge_request`. | Bound MR IID/project path, approved/reviewed SHA. | Bind fresh MR head/caller; approval is not independent exact-SHA review evidence.
