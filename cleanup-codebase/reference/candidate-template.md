# Candidate template

Use this shape for every proposed cleanup slice:

- **Title**: action-oriented deslop or destale slice.
- **Evidence**: exact files/lines, commands, docs, or tests; negative checks run; every item required by the applicable [gate sequence](gates.md); graph leads and edge confidence separated from proof.
- **Why now**: maintenance pain, risk reduction, reviewability, onboarding, or CI clarity.
- **Scope**: included surfaces, explicit out of scope, and uninspected surfaces.
- **Risk**: behavior, runtime, operator, security, data, and review impact.
- **Validation**: tests, check gate, docs link check, dry run, grep proof, graph query, or manual review.
- **Effort / Confidence**: S/M/L with reason. High requires every proof gate; Medium/Low names missing or partial proof and cannot be AFK.
- **Type**: AFK / HITL / Needs info.
